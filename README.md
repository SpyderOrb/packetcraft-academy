# Packetcraft Academy

A responsive, single-page portfolio concept for a practical networking certification school. The site is built with plain HTML, CSS and JavaScript and has no build step or package dependencies.

Course schedules, program figures, reflections and form responses are intentionally illustrative portfolio content, not operational claims.

## Run locally

From this directory, start any static server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

You can also open `index.html` directly in a browser, although a local server is preferable.

## Features

- Responsive desktop and mobile layouts
- Keyboard-friendly pathway tabs and mobile navigation
- Accessible labels, focus states and semantic landmarks
- Animated SVG lab topology and purposeful scroll reveals
- `prefers-reduced-motion` support
- Client-side form validation and success feedback
- No external runtime dependencies
